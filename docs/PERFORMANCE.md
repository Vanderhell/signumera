# Performance and footprint

No isolated MCU benchmark has been performed. The ESP32-S3 validation was functional only; it does not establish execution time or resource use for a production application.

Flash size, static RAM, stack depth, worst-case timing and per-operation cycle counts are **NOT MEASURED**. They depend on selected translation units, target, compiler, flags, link-time optimization and caller context. Do not treat the temporary Arduino sketch size as a library benchmark.

For publishable measurements, record target revision, clock, compiler/toolchain version, optimization flags, linked functions, input distribution, repetition methodology and observed stack/RAM/flash/timing.
